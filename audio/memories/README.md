# Memory voice clips (optional)

Drop recorded clips here and the game uses them instead of its synthesized voices.
All are optional; missing files fall back automatically.

| File | Used for |
|---|---|
| `beef.mp3` | "ah beef beef beef beef" on Big Island |
| `laugh1.mp3`, `laugh2.mp3`, `laugh3.mp3` | boys laughing (picked at random) |
| `shout_hey.mp3`, `shout_woo.mp3`, `shout_go.mp3`, `shout_yeah.mp3`, `shout_dude.mp3`, `shout_oh.mp3` | excited shouts |

Short, dry recordings work best; the game adds distance, echo and reverb across the water.
